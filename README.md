\# 📦 食品评论情感分析项目和VC 等项目相关分析笔记本过程



\## 项目简介

本项目是针对\*\*食品评论数据\*\*的情感分析实践，通过 Python 与 Jupyter Notebook 完成从数据采集、清洗到情感分类、结果可视化的完整流程，可用于食品口碑分析与用户偏好研究。

|文件名|类型|用途|
|-|-|-|
|01\_food\_science\_analysis\_collection.ipynb|Jupyter Notebook|VC 等项目相关分析笔记本（非本项目主分析流程）|
|analyze.py|Python 脚本|食品情感分析核心逻辑（本项目主分析脚本，可独立运行）|
|report.py|Python 脚本|生成分析报告与图表|
|comments.xlsx|Excel 数据|原始食品评论数据集|
|comments\_with\_sentiment.xlsx|Excel 数据|标注情感标签（正面 / 负面 / 中性）的结果集|
|sentiment\_pie\_chart.png|图片|情感分布饼图（可视化结果）|
|shiyongshouce.docx|Word 文档|个人使用操作手册与结果说明|



\## 技术栈

\- \*\*语言\*\*：Python

\- \*\*工具\*\*：Jupyter Notebook、Pandas、Matplotlib

\- \*\*任务\*\*：文本情感分析、数据可视化



\## 使用说明

1\.  打开 `01\_food\_science\_analysis\_collection.ipynb` 可查看完整分析流程

2\.  运行 `analyze.py` 可快速执行情感分析

3\.  数据文件可直接用于后续模型训练或其他分析
